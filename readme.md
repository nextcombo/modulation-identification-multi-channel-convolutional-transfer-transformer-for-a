# [Modulation Identification] Multi-Channel Convolutional Transfer Transformer for Automated Modulation Identification [with MATLAB Code]

Introduction  
Automatic Modulation Classification (AMC) is a key technology in wireless communication systems, aiming to automatically identify the modulation type of radio time-series signals. For an effective wireless communication system, accurately identifying the modulation pattern of the signal transmitted is essential. Therefore, AMC plays a crucial role in practical applications and has many combinations with machine learning techniques to improve recognition performance [3].  
Currently, AMC methods can be broadly divided into two categories: likelihood-based (LB) methods [4]-[7] and feature-based (FB) methods [8]-[11]. The LB method classifies signals by formulating the AMC problem as a hypothesis test and calculating the likelihood of the received signal. However, they require prior knowledge about channel conditions, and are easily affected by real-world factors such as channel fading and time delays in complex modern communication systems, which have limited practical value. Compared to the LB method, the FB method typically employs feature extractors and machine learning-based classifiers to identify the modulation category. In traditional FB methods, feature extractors are designed based on expert knowledge. For example, using empirical formulas [10] or [11] to extract various higher-order cumulants from raw signals as feature values. This means that traditional FB methods struggle to adapt to different wireless scenarios, such as various SNR environments. Fortunately, FB methods can conveniently integrate with deep learning techniques by cascading feature extractors and classifiers into a complete neural network. This allows AMC methods to benefit from the representational learning capabilities of deep neural networks (DNN), enabling automatic learning of useful, multi-level, and advanced features from raw signals using a generalized learning process.
The feature learning capability of DNN models has been utilized in many deep learning techniques for extracting signal features using end-to-end methods, which are applied to AMC tasks [15]. O'Shea and West [16] proposed pioneering work on predicting modulation categories using DNN. The authors employed two convolutional neural networks (CNNs) with identical but different filters to learn numerous time-related features. Liu et al. [17] applied Convolutional Long Short-Term Memory (CLDNN), stacking the Long Short-Term Memory (LSTM) layers on top of four CNN layers to learn time-domain waveforms from raw signals. Due to the fact that radio time series signals include both I/Q channels, Xu et al. [19] introduced Multi-Channel Convolutional Long Short-Term Memory (MCLDNN) to supplement networks with independent I/Q channel inputs to fully extract time-related features. To further identify temporal correlations in the time domain, Kong et al. [20] proposed a Convolutional Transformer Deep Neural Network (CTDNN), coupling the Transformer [21] to an embedding module based on CNN. However, the recognition performance of AMC methods solely learning features from the time domain is still unsatisfactory. Since radio signals can be described as the sum of infinitely many sinusoidal waves each with its own frequency, enhancing the modulation classification performance by characterizing frequency characteristics is valuable, but these works have overlooked this aspect.
To utilize signal characteristics in the frequency domain, some research has been conducted. For example, Yashashwi et al. [22] utilized a correction module based on a multilayer perceptron (MLP) before a CNN-based module to eliminate frequency and phase distortions caused by wireless channels. Hou et al. [23] used Fast Fourier Transform (FFT) to obtain frequency information from the time domain, then constructed a complex CNN for modulation recognition. Zhang et al. [24] established an AMC-Net framework that applies FFT to the raw signal to learn global filters from the frequency domain. Considering different frequency bands of signals, the authors further proposed an adaptive wavelet network (AWN), which combines multilevel wavelet decomposition with attention mechanisms to extract and select frequency features [25]. These attempts have demonstrated the crucial role of frequency information for AMC. However, the interaction between different features in both the time and frequency domains has received little study.
In summary, previous research has mainly focused on partial features [17], [19], [25], and adopted simple modules that may not fully learn complex patterns present in the signal [24]. In this regard, this paper proposes a new method called Multi-Channel Convolutional Transfer Transformer (MCDformer) for AMC, including a Frequency Domain Denoising Module (FDDM), CNN backbone, and Transfer Transformer module (DTM). The main contributions are summarized as follows.
· A new AMC framework, MCDformer, is proposed that can harvest various different features of radio signal harvesters, fully utilize inherent information in the signal, and thus improve classification performance.
· To fully exploit frequency domain information, a novel and concise Frequency Domain Denoising Module (FDM) is proposed. This algorithm effectively captures the real and imaginary parts of the signal, significantly improving denoising performance at lower computational complexity.
· To effectively capture the correlation between different features while focusing on more discriminative patterns, we propose an Extractive Transformer module (DTM). The DTM architecture introduces an extraction layer between two Transformer modules to extract attention maps and reduce computational complexity.
· Experimental results on two typical datasets demonstrate that the classification performance of MCDformer significantly outperforms existing baselines, verifying the effectiveness of the method.
Article illustration
Conclusion
This paper presents a novel multi-channel convolutional distillation Transformer (MCDformer) model for automatic modulation classification, composed of a frequency domain denoising module (FDDM), CNN backbone, and distillation Transformer module. In MCDformer, the FDDM utilizes frequency domain information to effectively denoise the input signal. After extracting waveform features from the signal through the CNN backbone, the DTM captures temporal features and learns the correlation between different features. Additionally, the distillation layer in DTM condenses feature information and reduces computational complexity. MCDformer can effectively integrate various features of radio signals, fully exploit potential information in the signal, thereby significantly improving classification performance. Our future work will continue to improve classification accuracy in lower SNR environments.
